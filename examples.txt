# 网络安全信息收集工具 - 使用示例

## 基本用法

### 1. 扫描单个目标

# 扫描所有模块
python main.py -t example.com -m all

# 扫描特定模块
python main.py -t example.com -m subdomain,port,dns

# 指定线程数和超时时间
python main.py -t example.com -m port --threads 50 --timeout 10

# 生成HTML报告
python main.py -t example.com -m all -o report.html

# 生成JSON报告
python main.py -t example.com -m all -o report.json


### 2. 扫描多个目标

# 从文件读取目标列表
python main.py -f targets.txt -m all -o batch_report.html

# targets.txt 格式（每行一个目标）
# example1.com
# example2.com
# 192.168.1.1
# 192.168.1.0/24


### 3. 使用自定义字典

# 子域名扫描使用自定义字典
python main.py -t example.com -m subdomain --wordlist my_subdomains.txt

# 目录扫描使用自定义字典
python main.py -t example.com -m dir --wordlist my_directories.txt

# 端口扫描指定范围
python main.py -t example.com -m port --wordlist "1-1000"
python main.py -t example.com -m port --wordlist "80,443,8080,8443"


### 4. 详细控制选项

# 详细输出模式
python main.py -t example.com -m all -v

# 指定配置文件
python main.py -t example.com -m all --config custom_config.yaml

# 控制日志级别
python main.py -t example.com -m all -v --log-level DEBUG


### 5. API模式使用

# 启动API服务器
python main.py --api --port 8080

# API使用示例 (Python)
```python
import requests
import time

# 创建扫描任务
response = requests.post('http://localhost:8080/api/v1/scan', json={
    'target': 'example.com',
    'modules': ['subdomain', 'port', 'vuln'],
    'threads': 30,
    'timeout': 5
})

task = response.json()
print(f"任务ID: {task['task_id']}")

# 查询任务状态
while True:
    response = requests.get(f"http://localhost:8080/api/v1/scan/{task['task_id']}")
    task_info = response.json()
    
    print(f"状态: {task_info['status']}")
    
    if task_info['status'] in ['completed', 'failed']:
        break
    
    time.sleep(2)

# 打印结果
if task_info['status'] == 'completed':
    import json
    print(json.dumps(task_info['result'], indent=2))
```


## 模块详解

### 子域名扫描 (subdomain)
- DNS区域传输（如果允许）
- 搜索引擎发现（crt.sh、CertSpotter等）
- 字典暴力破解
- 支持自定义DNS服务器

### 端口扫描 (port)
- TCP端口扫描
- SYN扫描（需要管理员权限）
- Banner抓取
- 服务版本识别

### 服务识别 (service)
- 基于Banner的服务识别
- 版本信息提取
- CPE（通用平台枚举）生成
- 操作系统指纹识别

### DNS记录 (dns)
- 支持A、AAAA、MX、NS、TXT、CNAME、SOA、PTR等记录类型
- DNS服务器配置
- 区域传输尝试

### WHOIS查询 (whois)
- 域名注册信息
- 注册商信息
- 创建/过期日期
- 名称服务器

### 目录扫描 (dir)
- 网站目录枚举
- 文件发现
- 状态码分析
- 目录列表检测

### 漏洞检测 (vuln)
- XSS漏洞检测
- SQL注入检测
- 命令注入检测
- 安全头检查
- SSL/TLS配置检查
- 信息泄露检测

### SSL分析 (ssl)
- 证书有效性检查
- 过期时间监控
- 证书链验证
- 加密套件分析
- 协议版本检测

### 网络拓扑 (network)
- 路由追踪（traceroute）
- 网络信息收集
- 操作系统TTL指纹


## 实际应用场景

### 场景1: 网站安全评估
```bash
# 对目标网站进行全面的安全评估
python main.py -t target.com -m all -o security_audit.html

# 重点关注漏洞和SSL配置
python main.py -t target.com -m vuln,ssl -o vuln_report.html
```

### 场景2: 子域名收集
```bash
# 全面的子域名收集
python main.py -t target.com -m subdomain --threads 100 -o subdomains.html

# 结合暴力破解和搜索引擎
# 配置文件设置: subdomain.brute_force=true, subdomain.search_engines=true
```

### 场景3: 网络资产发现
```bash
# 扫描内网资产
python main.py -t 192.168.1.0/24 -m port,service -o network_assets.html

# 扫描特定端口范围
python main.py -t 192.168.1.0/24 -m port --wordlist "21,22,23,80,443,3389" -o critical_ports.html
```

### 场景4: 渗透测试前的信息收集
```bash
# 全面的信息收集
python main.py -t target.com -m subdomain,port,service,dir,vuln -o recon_report.html

# 快速扫描，准备后续测试
python main.py -t target.com -m subdomain,port --threads 200 -o quick_recon.html
```

### 场景5: 定期安全监控
```bash
# 创建目标列表文件
echo "example1.com" > monitoring_targets.txt
echo "example2.com" >> monitoring_targets.txt

# 批量扫描
python main.py -f monitoring_targets.txt -m ssl,vuln -o monthly_report.html

# 关注证书过期
python main.py -f ssl_targets.txt -m ssl -o cert_monitoring.html


## GUI图形界面模式

### 启动GUI
```bash
# 方式1: 使用main.py启动
python main.py --gui

# 方式2: 使用专用GUI脚本
python gui.py

# 指定端口
python main.py --gui --gui-port 8080
```

### GUI操作步骤

1. **打开浏览器访问**
   - 自动打开: http://localhost:5000
   - 或手动访问: http://localhost:5000

2. **输入扫描目标**
   - 在左侧"目标列表"文本框中输入域名或IP
   - 每行一个目标
   - 示例:
     ```
     example.com
     192.168.1.1
     test.example.com
     ```

3. **选择扫描模块**
   - 勾选需要的扫描模块
   - 或点击"全选"选择所有模块
   - 使用"快速预设"快速加载常用配置:
     - 信息收集: subdomain + dns + whois
     - 安全评估: port + service + vuln + ssl
     - 网络探测: port + service + network

4. **设置扫描参数**
   - 线程数: 默认30，可根据网络环境调整(1-200)
   - 超时时间: 默认5秒，网络较差时可增加(1-300秒)

5. **开始扫描**
   - 点击"开始扫描"按钮
   - 右侧显示实时进度条和当前扫描目标
   - 可以查看每个目标的扫描状态

6. **查看结果**
   - 扫描过程中实时显示结果
   - 按目标分组显示
   - 不同模块的结果分类展示
   - 漏洞和警告用不同颜色标识

7. **下载报告**
   - 扫描完成后显示"下载报告"按钮
   - 点击下载HTML格式的详细报告
   - 报告包含所有扫描结果和统计信息

### GUI界面特点

- **现代化界面**: 基于Bootstrap的响应式设计
- **实时更新**: 使用WebSocket实时推送进度

- **进度可视化**: 进度条显示整体进度
- **结果高亮**: 重要信息用颜色区分
- **移动适配**: 支持手机和平板访问

## 性能调优建议

### 大规模扫描
```bash
# 1. 调整线程数（根据网络和系统性能）
python main.py -t target.com -m all --threads 100

# 2. 调整超时时间（网络环境较差时）
python main.py -t target.com -m all --timeout 10

# 3. 分阶段扫描（减少资源占用）
python main.py -t target.com -m subdomain -o stage1.html
python main.py -t target.com -m port,service -o stage2.html
python main.py -t target.com -m vuln,ssl -o stage3.html
```

### 扫描策略
1. **快速扫描**: 使用较少的线程和超时时间
2. **深度扫描**: 使用更多线程和较长的超时时间
3. **针对性扫描**: 只选择需要的模块
4. **批量扫描**: 使用目标文件进行批量处理

## 故障排除

### 常见问题

1. **端口扫描需要管理员权限**
   - Linux/macOS: 使用 `sudo`
   - Windows: 以管理员身份运行

2. **网络连接问题**
   - 检查网络连接
   - 调整超时时间: `--timeout 10`
   - 检查防火墙设置

3. **内存占用过高**
   - 减少线程数: `--threads 20`
   - 分批扫描目标

4. **API服务器无法访问**
   - 检查端口是否被占用
   - 检查防火墙设置
   - 确认CORS配置（如果需要跨域访问）
