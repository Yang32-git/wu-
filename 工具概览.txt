二、已实现的10个功能模块
========================================================================

1. 子域名扫描器 (subdomain_scanner.py)
   - DNS区域传输
   - 搜索引擎发现（crt.sh、CertSpotter等）
   - 字典暴力破解
   - 多线程并发验证

2. 端口扫描器 (port_scanner.py)
   - TCP端口扫描
   - SYN扫描（需管理员权限）
   - Banner抓取
   - 服务版本识别

3. 服务识别器 (service_scanner.py)
   - 20+种常见服务识别
   - 版本信息提取
   - CPE生成
   - OS指纹识别

4. DNS记录扫描器 (dns_scanner.py)
   - 支持A/AAAA/MX/NS/TXT/CNAME/SOA/PTR记录
   - 自定义DNS服务器
   - DNS区域传输尝试

5. WHOIS查询器 (dns_scanner.py)
   - 域名注册信息
   - 注册商信息
   - 创建/过期日期

6. 目录扫描器 (directory_scanner.py)
   - 网站目录枚举
   - 文件发现
   - 状态码分析
   - 敏感文件检测

7. 漏洞检测器 (vulnerability_scanner.py)
   - XSS漏洞检测
   - SQL注入检测
   - 命令注入检测
   - 安全头检查（CSP/HSTS等）
   - SSL/TLS配置检查
   - 信息泄露检测
   - 风险等级评估

8. SSL证书分析器 (ssl_scanner.py)
   - 证书有效性检查
   - 过期时间监控
   - 证书链验证
   - 加密套件分析
   - 协议版本检测

9. 网络拓扑扫描器 (ssl_scanner.py)
   - 路由追踪（traceroute）
   - 网络信息收集
   - TTL操作系统指纹

10. 核心扫描引擎 (recon_engine.py)
    - 多模块协调调度
    - 线程池管理
    - 统一的扫描接口

四、使用方法
========================================================================

【演示功能】
python demo.py

【基本扫描】
python main.py -t example.com -m all

【指定模块】
python main.py -t example.com -m subdomain,port,dns

【生成报告】
python main.py -t example.com -m all -o report.html

【批量扫描】
python main.py -f targets.txt -m all -o batch_report.html

【API模式】
python main.py --api --port 8080

七、注意事项
========================================================================

1. 由于Jinja2/MarkupSafe版本兼容性问题，建议：
   - 使用Python虚拟环境
   - 或降级MarkupSafe: pip install markupsafe==2.0.1

2. 端口扫描可能需要管理员/root权限

3. 大规模扫描时建议调整线程数，避免对目标造成压力

4. 本工具仅供教育和授权测试使用
